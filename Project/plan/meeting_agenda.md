## 1. สภาพข้อมูล

**ที่มีแล้ว**
- ข้อมูลดิบครบ 4 เดือน (พ.ย.–ธ.ค. 2024, พ.ค.–มิ.ย. 2025) ≈ 3.6 GB + ตาราง `condition`, `market_data`
- ตารางเทรดที่ clean แล้วของ 2 สัปดาห์ที่ใช้ทดสอบ (`data/interim/`)
- ตรวจแล้ว: token ที่ map ไม่ได้ = 0 · self-trade = 0 · แถวดิบเกือบครึ่งเป็นแถวซ้ำที่ต้องตัด

**ปัญหาที่รู้แล้ว**
- ไม่รู้ position ที่เปิดก่อนหน้าต่างเวลา → ตลาดที่เปิดนานอาจถูกนับ closure เกิน
- ตลาด "Trump inaugurated?" ถูกติดธง 89% แต่เปเปอร์ไม่ติดเลย
- ตลาดไม่มีชื่อราว 39% → กระทบ EDA รายหมวด

**ต้องตกลง**
- [ ] **แชร์ข้อมูลอย่างไร** — เสนอ: แต่ละคนโหลดเองด้วยคำสั่งใน `01_Raw_Data/README.md` (ไม่อัป 3.6 GB ขึ้น Drive)
- [ ] **แก้ปัญหาขอบหน้าต่างวิธีไหน** — ขยาย lead-in / กรองเฉพาะตลาดที่ทั้งอายุอยู่ในช่วง / ทำทั้งสองแบบแล้วเทียบ
- [ ] **เพิ่มช่วง ต.ค. 2025 ไหม** — เสนอ: ทำเฉพาะถ้าเฟส 2 เสร็จตามกำหนด (เป็นงานแรกที่ตัดได้)
- [ ] **ห้ามดึงข้อมูลปี 2026** (9–21 GB/เดือน) — ทุกคนรับทราบ
- [ ] **C เริ่ม EDA รอบแรกหลังประชุมเลย** บนข้อมูล 2 สัปดาห์ใน `data/interim/` ไม่ต้องรอใคร → ส่งข้อสังเกต
  (ตลาดไร้ชื่อ, ตลาดที่เปิดก่อน lead-in, degree แปลก ๆ) ให้ A/B ภายใน **4 ต.ค.**
